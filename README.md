### Технологии

- Nuxt 4  
- Vue 3 (Composition API)  
- TypeScript  
- CSS (нативный / модульный)

---

### Запуск

```bash
# 1. Клонирование
git clone https://github.com/ArtemXYZ/parentage-frontend.git
cd parentage-frontend

# 2. Установка зависимостей
pnpm install
# или npm install / yarn install / bun install

# 3. Разработка
pnpm dev
# → http://localhost:3000
